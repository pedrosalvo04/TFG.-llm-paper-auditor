Extrae una lista estructurada de criterios de evaluación a partir del siguiente documento de directrices.

El documento contiene una serie de reglas, requisitos o preguntas que deben ser evaluadas en un artículo científico.
Tu tarea es parsear este texto y devolver un JSON puro que siga estrictamente este formato:

```json
{
  "clave_corta_1": "Descripción completa y literal del criterio 1 tal y como aparece en el texto o resumida para que un auditor la entienda perfectamente.",

  ...
}
```

Reglas:
1. Extrae TODOS los criterios mencionados en el texto.
2. Cada clave debe ser un string corto (máximo 3-4 palabras) en inglés, usando snake_case (ej. `data_availability`, `ethical_implications`).
3. El valor debe contener la explicación completa de qué se pide en ese criterio.
4. Devuelve ÚNICAMENTE el bloque JSON, sin texto adicional antes ni después.
